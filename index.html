El desafío que más me hizo crecer

Alke Wallet

Descripción de la actividad

El proyecto Alke Wallet consiste en el desarrollo de una plataforma que pueda ser usada por una fintech (ficticia en este caso) para poder realizar transacciones, registrarlas y guardarlas en una base de datos.

Desafío principal

Mi desafío principal fue entender la plataforma Django. A pesar de tener conocimientos de Python y otras tecnologías, Django resultó ser un sistema que requería un entendimiento más profundo sobre cómo funcionan las webapps.

Solución propuesta

Principalmente, recurriendo a foros y documentación de Django. También entendiendo como funcionan en conjunto las diferentes tecnologías requeridas en este proyecto, tales como MySQL o los entornos virtuales.

Herramienta técnica utilizada

Usé VSCode con Django, principalmente porque se debe sacar partido a las herramientas que ya se poseen. Lo importante es conocer lo que ya tengo, cómo sacarle provecho, y en base a eso, poder continuar con el proyecto.
